# Release Notes: v1.60.0 (Initial Proof-of-Concept)

**Release Date:** 2026-08-15  
**Codename:** Genesis Spark

---

## Overview
Initial proof-of-concept release providing native Playwright browser automation on Android Termux (ARM64/aarch64) without requiring root permissions, PRoot containers, or heavyweight X11 desktop virtualization.

---

## Key Features

### 1. Platform Detection & Core JS Patching
* Basic regular-expression patcher targeting coreBundle.js to bypass Playwright's hardcoded platform verification checks (process.platform !== 'android').
* Enabled direct execution of Chromium on Android Bionic libc.

### 2. Basic Installation Script
* Provided an initial shell script (install.sh) to download Playwright wheels and configure Termux system binaries (chromium, 
odejs, python).

### 3. Proof-of-Concept Crawler
* Provided sample asynchronous scripts demonstrating successful page navigation and DOM title extraction on Android devices.

---

## Known Limitations in v1.60.0
* Used indiscriminate process killing (pkill -f chromium), causing collateral termination of user's unrelated browser tabs.
* Relied on temporary /tmp storage without automatic stale profile cleanup.
* Lacked strict signal chaining, causing zombie processes when Termux sessions were closed abruptly.
