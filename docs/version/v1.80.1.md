# Release Notes: v1.80.1 (Two-Phase Bootstrap & Diagnostics Aliases)

**Release Date:** 2026-08-26  
**Codename:** Fortress Bootstrap  
**Supported Platforms:** Android Termux (`aarch64`, `x86_64`), Android 10 ~ 15+ (Samsung Galaxy S20, S21, A34/A35, and modern ARM64/Bionic devices).

## Overview

`v1.80.1` is a critical patch release resolving clean-slate provisioning errors on fresh Android Termux setups, while introducing extended diagnostic function aliases and process-level automatic environment configuration hooks for vanilla Playwright consumers.

Verified with **100% PASS** on physical **Samsung Galaxy S20** (Snapdragon 865) and **Galaxy A34/A35** (Dimensity/Cortex-A78/A55) hardware testbeds.

---

## Key Improvements & Bug Fixes

### 1. Two-Phase X11 Repository Bootstrap (`installer.py`, `bin/cli.js`)
- **Root Cause**: On fresh Termux setups, APT cannot resolve `chromium` before `x11-repo` is installed and the APT cache is synchronized, triggering `Unable to locate package chromium (Exit Code 100)`.
- **Fix**: Separated provisioning into a deterministic two-phase pipeline:
  - **Phase 1**: Bootstraps `x11-repo` and immediately synchronizes APT repository indexes via `pkg update -y`.
  - **Phase 2**: Resolves and installs `chromium`, `nodejs`, `python-greenlet`, `procps`, and `termux-api` with zero mirror resolution failures.

### 2. Diagnostic Function Aliases (`installer.py`, `__init__.py`, `lib/index.js`)
- Exported backwards-compatible function aliases for seamless CI and test suite integration:
  - `run_doctor_health_check = doctor`
  - `run_doctor = doctor`
  - `check_health = doctor`
- Prevents `ImportError` when external automation scripts query health verification via alternative naming conventions.

### 3. Process Environment Auto-Configuration Hook (`__init__.py`)
- Automatically initializes `configure_environment(strict=False)` on module load (`import termux_playwright`).
- Auto-populates `PLAYWRIGHT_CHROMIUM_PATH` and `PLAYWRIGHT_NODEJS_PATH` into the current process environment, preventing vanilla Playwright (`from playwright.sync_api import sync_playwright`) from falling back to missing x86 cache directories.
