## Key Improvements & Additions

### 1. File-Backed Persistent Session Ledger (.tp_ledger)
* **Problem Solved:** When the Android kernel executes SIGKILL (Low Memory Killer / OOM), Python in-memory state is lost, leaving orphaned Chromium processes.
* **Solution:** Added disk-backed session ledger in $TMPDIR/.tp_ledger/ recording active session PIDs. Upon subsequent restarts, launch() automatically sweeps and reaps orphaned Chromium processes from previous hard crashes.

### 2. Stat-Driven Dynamic Chromium Version Tracking
* **Problem Solved:** Long-running crawlers in background daemons kept cached Chromium versions across pkg upgrade chromium, causing Client Hints version mismatches.
* **Solution:** Replaced static LRU cache with binary st_mtime stat checking. If Chromium is upgraded on disk, the version is refreshed in real time with 0ns overhead.

### 3. Prototype-Safe Stealth & Anti-Bot Evasion (setup_stealth_context)
* **Problem Solved:** Cloudflare Turnstile and DataDome detect Object.defineProperty(navigator, 'webdriver') due to hasOwnProperty('webdriver') === true and non-native function 	oString().
* **Solution:** Implemented prototype-chain deletion (delete Object.getPrototypeOf(navigator).webdriver; delete navigator.webdriver) and realistic window.chrome.app / 
untime simulation, native permissions.query.toString() spoofing, and standard Chrome PDF Viewer plugin definitions.

### 4. Android 14+ Single-Process Option (single_process=True)
* Added single_process=True flag to collapse all Chromium renderer/GPU/utility subprocesses into 1 process, cleanly bypassing Android 14's 32-process Phantom Killer.

### 5. Virtual Environment Isolation Guidance
* Automatically detects when running inside a Python env without --system-site-packages access to pre-compiled python-greenlet and raises clear, actionable resolution commands.

### 6. Storage Auto-Purge Rescue
* When /tmp storage drops below threshold during launch, automatically cleans unowned ephemeral profiles (	p_solo_*) using live OS PID verification before raising StorageExhaustionError.

### 7. Non-Daemon Teardown Bounded Latency
* Reduced discovery and cleanup subprocess timeouts to 1.0s to eliminate CLI exit latency while guaranteeing zero zombie leaks.
