## Key Improvements & Additions

### 1. Universal Runtime Adaptive Engine (Android 10 ~ 15+)
- **Android 14/15+ Phantom Process Killer Mitigation**: Automatically activates `--single-process` when running on Android SDK $\ge 34$ in Termux, bypassing the 32-process kernel limits.
- **Bionic Linker `EACCES` Resolution**: `find_chromium_binary()` automatically prioritizes the direct native ELF binary (`/usr/lib/chromium/chrome`) over shell wrapper scripts, preventing Android 14/15 `execve` script execution rejections.
- **Modern Chromium `--headless=new` Standardization**: Auto-injects `PLAYWRIGHT_CHROMIUM_USE_HEADLESS_NEW=1` and `PW_EXPERIMENTAL_CHROMIUM_USE_HEADLESS_NEW=1` into the driver environment to natively support modern Chromium builds where legacy `--headless=old` was removed.
- **eMMC Cache Conflict Resolution**: Replaced `--disk-cache-dir=/dev/null` with `--disk-cache-size=1` and `--media-cache-size=1` to eliminate `mkdir(/dev/null) EEXIST 17` startup crashes on modern Chromium.
- **Tier-1 OS Runtime Property Detection**: Prioritizes `getprop ro.build.version.sdk` and `/system/bin/getprop` to detect the live OS API level (e.g. API 35 on S21) rather than the static Python NDK compile-time target (API 30).

### 2. Next-Gen Anti-Detection Engine (`stealth`)
- **Sub-Pixel Canvas 2D LSB Noise**: Applies 1-bit XOR micro-noise to the top-left 10x10 pixel region of Canvas 2D render buffers, randomizing cryptographic canvas hashes per session with zero human-perceptible visual distortion.
- **AudioContext Frequency Jitter**: Injects $\pm 10^{-7}$ frequency deviation noise into `AudioBuffer` and `AnalyserNode` frequency spectrums to defeat modern audio fingerprinting.
- **WebGL UNMASKED Vendor & Renderer Mocking**: Emulates realistic GPU rendering contexts matching the host platform.

### 3. Fitts's Law & Human Interaction Engine (`physics`)
- **`HumanMouse` Cubic Bézier Trajectory**: Simulates non-linear hand movement curves with Fitts's law deceleration, realistic target overshoot, and physiological muscle tremor micro-jitter ($\sigma=1.2\text{px}$).
- **`HumanKeyboard` Log-Normal Typing Model**: Simulates natural human keystroke delay distributions ($\mu=120\text{ms}, \sigma=35\text{ms}$) with realistic bigram variations.

### 4. Dual-Mode Cellular IP Rotator (`mobile`)
- **`CellularIpRotator`**: Toggles mobile data or airplane mode in 2~3 seconds via `termux-telephony-data` (Termux Native mode) or `adb shell cmd connectivity` (PC ADB Bridge mode), with automated multi-endpoint public IP verification.

### 5. Automated WAF & Turnstile Bypass Solver (`waf`)
- **`TurnstileEvaluator`**: Automatically detects Cloudflare Turnstile, Cloudflare Managed Challenge, hCaptcha, and reCAPTCHA, orchestrating human-like mouse movement and click execution.

### 6. Automated One-Touch Provisioning Pipeline
- Updated `termux-playwright-install` and `bin/cli.js` with `x11-repo` and `procps` to ensure clean, out-of-the-box installation on fresh Termux setups in under 20 seconds.
