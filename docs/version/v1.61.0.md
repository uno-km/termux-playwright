# Release Notes: v1.61.0 (Principal Engineering Refactor)

**Release Date:** 2026-08-18  
**Codename:** Fortress Overhaul

---

## Overview
Major architectural overhaul transforming the codebase from an experimental script into a production-grade Python package with zero side-effects, deterministic process lifecycle management, and comprehensive testing.

---

## Key Improvements & Additions

### 1. Targeted Session Reaper (ProcessReaper)
* Replaced destructive pkill commands with compact 8-character session tags (--termux-session-id={uuid}).
* Implemented multi-tier process discovery (Tier 1: /proc iteration, Tier 2: pgrep, Tier 3: ps -efww).
* Integrated signal handler chaining (SIGINT, SIGTERM, SIGHUP) preserving user and framework hooks.

### 2. Hardware & eMMC Flash Wear Protection
* Injected RAM-based disk cache flags (--disk-cache-dir=/dev/shm, --disk-cache-size=1, --media-cache-size=1) to prevent NAND flash degradation on mobile devices.
* Pre-configured Node.js V8 heap limits (--max-old-space-size=512) to prevent memory leaks from crashing the Termux environment.

### 3. Standalone Fortress Mode & WakeLock
* Added standalone_mode=True to create clean-room ephemeral profiles auto-purged on exit.
* Added wake_lock=True with TermuxWakeLock to prevent CPU sleep during long scraping tasks.

### 4. Developer Tooling & Diagnostics
* Introduced CLI commands: 	ermux-playwright-install, 	ermux-playwright-doctor, 	ermux-playwright-patch, 	ermux-playwright-reap.
* Expanded test suite from 0 to 56 unit tests with 100% pass rate.
