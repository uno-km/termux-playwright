Termux-Playwright

Non-Root Chromium Browser Automation & CDP Engine for Android Termux

1-Line Quick Installation

Install the official package directly into your runtime:

pip install termux-playwright
# or: npm install termux-playwright

The Engineering Challenge

Official browser automation drivers fail on Android Termux due to missing X11/Wayland servers, glibc vs bionic ABI incompatibility, and sandboxing constraints.

The Architectural Breakthrough

Controls genuine Chromium processes via direct Chrome DevTools Protocol (CDP) WebSocket sessions on Android Bionic libc without root or graphical servers.

Key Capabilities & Built-in Hardening

Direct CDP Control Channel

Connects directly via Chrome DevTools Protocol without heavy WebDriver server binaries.

Non-Root Mobile Execution

Fully operational inside standard Termux without root privileges or custom ROMs.

Full Python & JavaScript APIs

Offers familiar Playwright-compatible async page navigation, selectors, and evaluation.

Supported Compute Kernels & Operations

Subsystem Category Operations & Kernels Status

Canonical Usage Example

from termux_playwright import chromium

async def main():
    browser = await chromium.launch(headless=True)
    page = await browser.new_page()
    await page.goto("https://uno-km.github.io/uno-km/")
    title = await page.title()
    print(f"Page Title: {title}")
    await browser.close()

import asyncio
asyncio.run(main())

import { chromium } from "termux-playwright";

const browser = await chromium.launch({ headless: true });
const page = await browser.newPage();
await page.goto("https://uno-km.github.io/uno-km/");
console.log("Title:", await page.title());
await browser.close();
